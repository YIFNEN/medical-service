# 설계 판단과 문제 해결

## 출처와 검수를 데이터 계약으로 유지

내용 해시와 원문 위치를 연결하고, 검수·수정·철회는 원장을 통해 보존합니다. 완료된 호출과 항목별 답변을 재사용해 장애 이후에도 재개할 수 있게 했습니다. 문서에 기재된 사실, 사용자 해석, 모델 의견은 서로 다른 상태로 취급합니다.

## 판단을 바꿀 문헌에 분석 자원 집중

지침과 체계적 문헌고찰도 대상·범위를 확인합니다. 제목과 초록의 포함·제외·불확실 판정에 이유를 남기고, 중요한 수치·효과 비교·개인 적용성·충돌에 선택적 전문 검증을 요청합니다. 기본 전문 분석 한도는 5편이며 한도 밖 후보를 제외로 위장하지 않습니다. 접근 가능한 범위와 실제 분석한 범위를 분리하고, 전문을 확보하지 못한 핵심 주장은 미해결로 남깁니다.

## 기하학적 계산과 임상 의미 분리

DICOM의 좌표와 간격을 확인한 뒤 Slicer에서 수동 기준점과 영역을 지정합니다. RAS/LPS 왕복, 원본 해시와 프레임을 검증합니다. 임의 각도를 임상적 변형 각도로 부르지 않으며 평가 영역이 있어야 영역 비율을 계산합니다. 미표시 조직을 정상으로 간주하지 않습니다.

## 비용과 장애를 실행 상태에 포함

호출마다 비용을 예약하고 승인 예산과 가격표를 실행에 고정합니다. 응답이 유실되면 예약을 유지하며, 가격 상한을 산정하지 못하거나 예산이 부족하면 추가 호출을 차단합니다. 이는 설정 가격에 따른 실행 제어이며 실제 청구액 보장은 아닙니다.

## Agent 하네스의 실행 책임

하네스는 모델의 판단을 둘러싼 입력·도구 호출·검수·상태·출력의 실행 경계를 담당합니다. 새로운 판단에는 새 실행을 만들며 원본 가공과 같은 실행의 완료 호출만 적합한 범위에서 재사용합니다.

| 경계 | 구현 위치 | 실행 시 확인하는 것 |
|---|---|---|
| 설정·입력 고정 | `settings.py`, `workflow.py`, `tribunal.py` | 실행별 설정·입력·정책 버전, 변경된 조건으로 재개 거부 |
| 도구 호출과 복구 | `call_cache.py`, `budget.py`, `ledger.py` | 승인·호출 전 예약·사용량·성공 응답 저장·중단 후 재개 |
| 세 검토 역할 | `tribunal.py` | OpenAI에 역할별로 독립 요청. 각 의견을 다른 두 역할이 비평하고 수정·종합 후 세 역할이 주장별로 검토 |
| 판단의 사용 자격 | `question_runtime.py`, `claim_grounding.py` | 질문별 허용 자료, 출처·수치·개인 조건 검사, 실패한 주장과 의존 행동 보류 |
| 의견 가림·봉인 | `blinding.py`, `clinician_comparison.py` | 검색·요청의 의견 유출 검사, 결과 봉인 후 별도 사후 비교 |
| 영상 후보 소견 | `image_pilot.py`, `call_cache.py` | 승인한 이미지 해시·시도 상한, 모달리티별 완료 기록, 봉인 후 판독 대조, 관찰 정정·철회 |
| 사람의 검수와 출력 | `case_context.py`, `imaging_cli.py`, `reporting.py` | 검수 이력·영상 원본 연결·제안의 조건과 미해결 사항 표시 |

추가검사도 같은 경계를 통과합니다. 자료 부족을 임의 진단으로 메우지 않고, 검사로 해결할 질문·결과에 따른 판단 변경·부담·긴급도·대안을 주장별로 검토합니다. 시험은 이 경계의 동작을 검증하며 실제 모델의 임상적 판단 능력을 보증하지 않습니다.

## 실제 오류 해결 사례

| 발견한 문제 | 수정과 검증 |
| --- | --- |
| 검수 값 A → B → A 수정에서 이전 이벤트 재사용으로 B가 최신으로 남음 | 수정 이벤트를 새로 남기고 연속 중복만 제거, 복원 회귀 테스트 |
| PDF 본문의 인용 논문을 해당 PDF 자체로 연결할 위험 | 첫 제목과 고유 DOI를 보수적으로 확인하고 모호한 연결 거부 |
| UTF-16 XML의 엔티티와 비본문 자료 처리 공백 | 안전 파서, 부록·본문 밖 표 수집, 읽지 못한 요소는 부분 분석 표시 |
| 마스크 전치 오류를 부피 비교만으로 놓칠 수 있음 | 실제 내보낸 마스크를 복셀 위치별로 비교 |
| 픽셀 형변환이 오염 값을 정상처럼 보이게 함 | 형변환 전 값과 범위를 확인 |
| 결과 파일 저장 실패가 Slicer 종료를 막을 수 있음 | finally에서 종료를 보장하고 새 결과 JSON으로 성공 판단 |

## 남은 검증

사람이 지정하는 해부학적 기준점·병변 영역의 전문가 비교, 반복성, GUI 사용성, 임상 프로토콜 정확도와 실제 제공자 실행이 남았습니다. 지원하지 않는 영상, 읽지 못한 ISO, 이미지 표·수식·스캔 전문은 미확인 상태를 유지합니다.
