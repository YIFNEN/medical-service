# MEDIC CLI 프로토타입 완성 기준 계획

기준일: 2026-10-29. 사용자가 승인한 M0–M7 계획을 개발 기준선으로 고정한다.
상태·오류·세부 결정은 [진행 기록](IMPLEMENTATION_STATUS_KO.md), 재현 명령은
[시험 가이드](PROTOTYPE_TEST_GUIDE_KO.md)에 누적한다. 수량 변경이나 오류 수정 때문에 이 계획을 다시 작성하지 않는다.

## 목표와 경계

개인의 의료자료와 장기 변화를 재사용 가능한 기록으로 가공하고, 최신 문헌과 세 모델을 이용해 현재 상태·진단 가설·예후·검사·치료 선택지를 분석하는 로컬 Agent를 완성한다.
Agent-first 설계를 우선한다. 가공은 재사용하고 새로운 자료·질문·문헌·모델에 대한 판단은 새 실행으로 만든다.
의료진 의견이나 AI 합의를 정답으로 삼지 않으며 관찰·계측·주장·경험·실제 행동·AI 추론을 구분한다.
세 제공자의 독립 분석과 의료진 의견 가림은 별도 기능이다. 결측은 관련 질문만 보류한다.
연구용 분석에서 자동 처방·치료를 실행하지 않는다. 계산 정확도·통합 작동·의견 차이·임상 정확도를 분리한다.

프로토타입 범위는 실자료 CLI 종단 실행, 개인 조건, 수동 영상 계측·지표 비교, 의료진 의견과의 사후 비교, 시험 가이드다.
웹 UI, 자동 분할·정합·변화 탐지, 모든 영상 형식, PostgreSQL·Temporal·Orthanc 전환, 대규모 임상 검증은 선행조건이 아니다.

명시한 CLI > JSON 설정 파일 > preset. 확정 설정을 실행·비용·문헌·보고서가 공유하고 실행 중 변경하지 않는다.
카드·고유 연구·전문 시도·확보·분석 수를 구분한다. 수량은 충분성 기준이 아니다.
한도 밖 후보는 대기, 읽지 않은 부분은 미분석, 근거 부족 주장은 보류한다.
무결성·인용·예산 예약을 해제하는 설정은 제공하지 않는다. 설정과 승인 예산 변경은 새 run으로 수행한다.

## M0 — 기준선·설정 통합

공개 저장소를 코드 기준으로 삼고 기존 개인 데이터와 개발 worktree를 보존한다.
버전된 처리 설정과 기존 옵션을 통합한다. `doctor`는 Python·SDK·Slicer·저장 경로·모델·가격·키 존재를 네트워크 없이 검사한다.
키 값은 출력하지 않는다. 새 기본 저장소는 `.medic`, 기존 명시 경로는 유지한다.
통과: 회귀시험 유지, 우선순위·비용 일치, 재개 설정 변조 거부, 과거 보고서 열기.

## M1 — 세 제공자 경로

`providers smoke`로 합성 입력의 구조화 응답·모델/응답 ID·사용량을 확인한다.
SDK별 요청과 실행 모델·가격·토큰을 고정한다. 합성 종단 시험으로 검색 계획→문헌→독립 의견→상호 비평→수정→종합→주장 검증→보고서를 연결한다.
실제 호출은 별도 승인 후 수행한다. 미승인은 오프라인 개발을 막지 않는다.
통과: 1차 의견 간 비공개, 의견마다 다른 두 제공자의 비평, 세 종합 검토, 실패 숨김·자동 대체 금지, 완료 호출 재사용, 불완전 보고서 완료 표시 금지.

## M2 — 기록·개인 조건

`ingest-inventory`는 검수 목록의 원본·압축 계보·해시를 재검증한다.
환자·episode·epoch·해부학·좌우를 별도로 기록한다. 관찰·의료진 주장·요청·시행·경험·실제 노출·파생 계측을 구분한다.
처방과 실제 행동을 혼동하지 않고 자기보고와 파생 노출를 이중 계수하지 않는다.
사건·검사·작성·발행일과 부분 날짜·불명확 선후, 미제공·미측정·평가불가·명시적 음성을 보존한다.
바이트 중복과 복사·정정·실제 반복검사를 구분하며 유사 기록을 자동 병합하지 않는다.
증상·기능·활동·제약·목표·우선순위를 버전 관리하고 고영향·충돌 우선 검수, 완료 검수 재사용을 지원한다.
통과: 다른 환자/좌우/episode 차단, 외상·재수술·금속 제거 이후 epoch 무조건 비교 금지, 출처·정정·조건 버전 추적.

## M3 — 질문·주장·개인 적용

일곱 발목 영역을 유지하며 현재 상태, 예후, 치료효과, 선택 질문으로 구분한다.
대상·평가 시점, 예측 기간/outcome/치료 상태, 중재/비교대안/time zero, 개인 목표/제약/우선순위를 각각 요구한다.
질문별 허용 사실·계측·문헌 ID·결측을 고정한다. 문장·행동을 주장 ID에 연결한다.
답변 가능·조건부·자료 부족·범위 밖·충돌·시스템 실패와 자료/계측/모델/문헌/적용 불확실성을 구분한다.
누락된 예후 기간·비교 조건·선호를 발명하지 않고 검증되지 않은 개인 위험 백분율·NNT·절대 치료효과를 금지한다.
검사는 해결 질문·결과별 변경·부담·긴급도·대안에 연결한다.
통과: 부족한 질문만 보류, 모든 주장·수치·행동의 출처/명시 추론 추적, 일괄 보류·결측 추정 금지.

## M4 — 문헌 검증

지침·체계적 고찰 우선→초록 선별→선택 전문. 반대 근거·적용 제외·선별 이유를 기록한다.
동일 논문과 동일 연구의 여러 보고서를 구분하고 고찰과 포함 원연구를 독립 연구처럼 세지 않는다.
지원 출처의 철회·정정 확인과 확인 불가를 구별한다. 대상·방법·제외·결과·표·추적·한계를 필요한 깊이로 읽는다.
핵심 구간과 전체 열람을 구분하며 미확인 구간이 필요한 주장만 보류한다.
정식 편향 평가·GRADE·메타분석 미수행 상태를 명시한다.
통과: 수량/범위/비용 일치, 반복 인용·표 수치·분모·단위·방향·적용성 확인, 미확보/한도를 제외나 완료로 바꾸지 않음.

## M5 — Slicer 계측·장기 비교

측정 ID·이름·대상·좌우·기준점·방법/프로토콜 버전·평가면·촬영 조건·검수자를 보존한다.
CLI로 선택 시리즈를 표준 Slicer에 열고 결과를 가져온다. 두 점 거리·세 점 각도를 명시적으로 짝지으며 기존 수동 영역을 유지한다.
대상·epoch·지표·방법·단위·촬영 조건을 확인한다. 서로 다른 검사 좌표를 직접 빼지 않는다.
값·수치 차이·임상 변화는 별개다. 반복 오차 미확인 시 변화 입증 금지, 오차 이내를 자동 안정으로 부르지 않음, 임의 각도에 변형 명칭 금지.
통과: 합성 오차 ≤1e-6, Slicer 왕복, 사람 지정 계측의 입력/수정/철회, 조건 불일치 제한, 실제 두 시점 부재는 미검증.

## M6 — 의견 가림·봉인·사후 비교

일반/가림 모드를 구분한다. 가림에는 검수 직접 관찰·적격 실제 행동·본인 경험·계측·개인 조건을 제공한다.
의료진 해석·예후·권고·기관 제약·전언·과거 AI 결론은 별도 묶음에 보존한다.
검색·요약·이미지·오류의 간접 유출도 확인한다. cutoff와 해시 고정, 결과 봉인 후 비교만 허용한다.
일치·충돌·전제/시간 차이·근거 부족으로 설명하고 의견 일치율을 정확도로 쓰지 않는다.
새 관찰은 새 독립 실행을 먼저 만든다. 사후 비교는 기존 결과를 덮어쓰지 않는다.
통과: 가린 내용 요청/검색/보고서 유출 금지, 봉인 전/다른 사례 비교 거부, 양측 주장 출처 대조.

## M7 — 실자료·가이드

최대 문서 3개와 적합 CT 1개로 시작한다. 전체 적합성은 갱신하지만 전체 유료 처리는 하지 않는다.
검수→개인 조건→질문→문헌→세 판단→보고서→사후 비교와 수정/철회/중단/재개/후속 자료 새 판단을 시험한다.
기능·오프라인·실제 실행·임상 검증을 구분한다.
통과: 세 제공자와 주장 검증 완주, 재개 중복 호출 없음, 과거 보고서 불변, 미해결 항목 공개.

## 인터페이스·필수 시험

준비: `doctor`, `ingest-inventory`, `case status`. 조건: `case profile/review-input/questions`.
실행: `providers smoke`, `deliberate`, `resume`, `report`.
영상: `dicom launch-review/compare-measurements`. 비교: `compare-runs`, `compare-clinician`.
기존 명령과 사실 ID를 유지하고 새 검수·연결 버전에서 참조한다.

필수 회귀는 환자/좌우/episode 혼입, 부분 날짜/결측, 처방/실제 행동/파생 이중 계수,
복사/정정/반복 및 무효화, 설정/동시 예산/응답 유실/재개, 제공자 누락/잘림/스키마/가짜 인용,
전문 부분/미확보/반대 근거, 영상 방법/조건/원본 불일치, 의견 유출/미봉인/변조,
근거 없는 개인 위험/인과효과/임상 변화다. 추출은 원문 대조, 임상 의견은 정답이 아닌 비교 자료다.

가이드는 설치·합성·자료 선택/검수·조건/질문·Slicer·별도 승인 실제 실행·가림/봉인·비교·복구·증빙을
정확한 PowerShell·ID/경로·예상 출력·합격 기준·실패 다음 행동으로 설명하고 합성 자료만 공개한다.

## 실행·데이터·최종 완료

단계마다 구현→실패 사례 시험→통합→문서→커밋. 상태는 미착수/구현 중/오프라인 검증/실제 검증 대기/완료.
원본 `D:\Documents\Medical` 읽기 전용. 개인 시험 저장소 `D:\Medic\.medic\prototype`.
DICOM 로컬, 외부 검색은 비식별 검색식, 유료 호출/개인 전송 별도 승인. 공개는 코드·합성·일반 문서만.

최종 완료는 소규모 실자료 세 제공자 완주, 출처·버전 연결, 수정/철회/재개/후속 자료,
수동 계측/비교와 제한 표시, 가림/사후 비교, 가이드 재현, 임상 정확도 과장 금지를 모두 충족해야 한다.
새 전문가·실제 outcome·자동 영상·대규모 임상 평가는 후속 단계다.
